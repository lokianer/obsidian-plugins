# Deck of Many Things D2 — Own decks, builder, reset — Implementation Plan

**Status:** built 2026-10-25; accepted in Obsidian on 2026-10-25.

**Goal:** Own decks drawn in the same tab, a deck builder (by hand, from the standard deck, from
pasted text or a JSON file) and a reset of the draw history.

**Spec:** `docs/superpowers/specs/2026-10-25-deck-of-many-things-design.md` §4. Decided with the
maintainer: import from pasted text and JSON; the reset offers both "history only" and "history and
every card back".

## Review Focus

1. **Import:** the text parser takes `Name — effect`, `Name: effect`, `**Name.** effect`, list and
   task items, table rows (skipping header and separator); JSON takes the object, an array of cards
   or of names; anything else is refused with a reason — Task 1.
2. **Own decks:** a returning deck keeps its cards except `leaves`; a non-returning deck ticks each
   card drawn; `ends` stops the drawing; the Fool / Jester / Idiot rules only in the standard deck —
   Task 2.
3. **Reset:** only the Draws lines (and, if asked, the ticks) change — Task 3.

### Task 1: `src/deck/own.ts` — draft cards, text and JSON import, the note text

### Task 2: rules for any deck; the note parser reads effects and indented lines

### Task 3: `resetDeck` in `src/deck/note.ts`; the store lists, loads, records and resets any deck

### Task 4: `src/obsidian/deck-builder.ts` (the dialog), the tab's deck picker, New deck, Reset

### Task 5: settings (`deckFolder`), example vault, docs, commit
