# Dice R1 — Engine, Dice Stage, Dice Tab, `dice:` in Notes, Log — Implementation Plan

**Status:** built 2026-10-26, accepted in Obsidian on 2026-10-26 ("es läuft alles") (the maintainer: "Passt so. Statt W20 kann es jeder beliebige Würfel sein.
Achte auf Überlappungen.").

**Goal:** Roll any formula with the dice on a stage modelled on Baldur's Gate 3, from a Dice tab
and from `dice:` inline code in notes, and offer each roll for tonight's session log.

**Spec:** `docs/superpowers/specs/2026-10-26-dice-design.md` §1, §1a, §2, §3 and §7 (phase R1).

## Review Focus

1. **Formulas** (`src/dice/formula.ts`, pure): `2d6+3`, `1d8+2d6-1`, `W20`, `d%`, `4d6kh3`,
   `2d20kl1`, `4d6dl1`, `d20+5 adv` / `dis` (also `Vorteil` / `Nachteil`), brackets, `*` and `/`;
   anything else is not a formula (null), so Dice Roller's own grammar stays untouched. A result
   keeps every die (kept or dropped) and its text: `d20+7 → 12 (5, +7)`.
2. **The stage** (`src/obsidian/dice-stage.ts`): every die in its own shape (d4 … d20, d100 as two
   d10), one or two in a ring, more in wrapping rows sized by count, up to twelve drawn; tumble,
   land, chips for the numbers in the formula, the total counting up, the verdict against an
   optional DC, golden rays for a kept natural 20; a click or Space skips; reduced motion shows the
   result at once. Each part has its own row, so nothing overlaps — checked in a browser at 320,
   480 and 900 px.
3. **The Dice tab** (`src/obsidian/dice-view.ts`): formula, Roll, d4–d100 buttons, normal /
   advantage / disadvantage, an optional DC, the stage, the history of this Obsidian session with
   Roll again and Log.
4. **`dice:` in notes** (`src/obsidian/dice-inline.ts`): Reading view (post processor) and Live
   Preview (an editor extension; the source shows while the cursor is in it); a click plays the
   stage in a small window (setting) and shows the total beside the button; `dice: [[…]]` waits
   for R2.
5. **Log and settings:** `SessionLog.offerLine(text, mode)` shared with the battle log; settings
   **Dice log** (ask / automatic / off) and **Dice animation** (stage / simple / off); log line
   `Rolled 2d6+3 → 10 (4, 3, +3)`, with a DC `… against DC 15: success`.

**New dev dependencies:** `@codemirror/view` and `@codemirror/state` — types only for the Live
Preview extension; Obsidian provides both at runtime and esbuild already keeps them external, so
nothing is bundled.
