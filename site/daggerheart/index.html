All plugins · Plugin 02 · planned

The same table, a different game. Daggerheart, next in the workshop.

A second plugin with the tools of dnd5e-byLokianer, made for Daggerheart: factions and the session log as they are, and the rest rebuilt for the game’s own rules — Hope and Fear, the spotlight, damage thresholds, domain cards. So far it is a roadmap; no code is written yet.

Read the roadmap See the D&D 5e plugin
Factions and the log. Folders, relations −5 … +5, the faction world, tensions, tonight’s session with loot — shared with the D&D plugin.
Adversaries and environments. The SRD’s stat blocks in a tab, in your notes with HP and stress slots, thresholds, features and countdowns.
Duality dice. Two d12 for Hope and Fear on the dice stage, doubles as a critical success, rolls from every stat block.
Combat and domain cards. The spotlight and the GM’s Fear instead of initiative, encounters by Battle Points, the nine domains as a card tab.

Licence and neighbours

Built on the SRD, next to the plugins that exist.

Daggerheart’s System Reference Document 1.0 is Public Game Content under the Darrington Press Community Gaming License: the plugin will ship SRD content only — nothing exclusive to the rulebook, no card art or logos — with the licence’s notice. Plugins like BeastVault and DaggerForge already show adversaries in Obsidian; this one aims to read their stat blocks where it can and to add what they leave out: the faction world, the session log and everything in one place, in English and German.
