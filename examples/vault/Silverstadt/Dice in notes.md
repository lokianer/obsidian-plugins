# Dice in notes

Inline code starting with `dice:` becomes a button in Reading view and Live Preview (Dice Roller writes it the same way).

- Orrin's Persuasion: `dice: d20+7`
- With advantage: `dice: d20+7 adv`
- A fireball: `dice: 8d6`
- New stats: `dice: 4d6kh3`
- German works too: `dice: 2W6+3`
- Percentile: `dice: d%`
- Every die at once: `dice: d4+d6+d8+d10+d12+d20`

Dice Roller's own grammar is left as it is, and so are tables until phase R2:

- Exploding dice: `dice: 1d6!`
- A table: `dice: [[Street Rumours#Night on Lantern Quay (d20)]]`
